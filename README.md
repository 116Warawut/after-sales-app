# AfterSales Dashboard (เว็บ Admin)

สอนรันเว็บแอดมิน

## วิธีรัน

1. เปิด terminal ในโฟลเดอร์นี้ แล้วรัน:
   ```
   npm install
   ```
   (ต้องต่ออินเทอร์เน็ต ใช้ครั้งแรกครั้งเดียว จะโหลดของที่โปรเจกต์ต้องใช้ทั้งหมดมาไว้ในเครื่อง)

2. รันเว็บ:
   ```
   npm run dev
   ```
   จะได้ลิงก์ขึ้นมา (ปกติคือ `http://localhost:5173`) เปิดในเบราว์เซอร์ได้เลย

## โครงสร้างไฟล์

- `src/AdminDashboard.jsx` — ไฟล์หน้าตาแดชบอร์ดหลัก (แก้ตรงนี้เพื่อปรับข้อมูล/ดีไซน์)
- `src/App.jsx` — จุดเรียกใช้ AdminDashboard
- ตอนนี้ข้อมูลทั้งหมดเป็น mock data (จำลอง) เก็บไว้บนสุดของ `AdminDashboard.jsx` ตอนต่อ Firebase จริง จะมาแทนที่ก้อนนี้ด้วยข้อมูลจริงจากฐานข้อมูล
